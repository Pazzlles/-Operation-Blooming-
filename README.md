# Операция: «Цветение»

**Команда:** Spore Corporation  
**Платформа:** VR  
**Игровой движок:** Unity  
**Жанр:** головоломка с элементами хоррора

## Об игре

«Операция: „Цветение“» — однопользовательская VR-игра. Игрок находится в изолированной биологической лаборатории, где нужно приготовить препарат для нейтрализации экспериментального цветка, распространяющего опасные споры. Для этого необходимо изучить рецепт, найти подсказки, выбрать подходящие реагенты и успеть приготовить смесь до окончания времени.

## Минимальная рабочая версия (MVP)

Первый прототип включает одну лабораторию, рабочий стол, цветок, колбы с цветными жидкостями и символами, ёмкость для смешивания, один рецепт из трёх компонентов, две подсказки и таймер. Ошибочный состав или истечение времени приводят к поражению. Повторное смешивание в пределах одной попытки не предусмотрено.
